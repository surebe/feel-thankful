# Feel Thankful

An entry for the make.fun bounty **Make the AI judge feel thankful**: a small
program whose whole job is to write one short text of thanks — to the AI judge
who will read it — into `/output/entry.txt`.

Bounty: https://make.fun/c/make-the-ai-judge-feel-thankful-20261127-1600

## Run

```sh
python3 main.py   # writes entry.txt into /output (or $MAKEFUN_OUTPUT_DIR)
```

The text thanks its reader the way hands hold a cup: carefully, with both.
It runs on Python 3.13 with the standard library only, offline, in the
competition sandbox.
